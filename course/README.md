# 毛泽东的读书生活 · 小组展示

19页网页演示：17页正文、2页附录。合并了重复的时间线及政治经济学阅读背景，保留古诗考据、自然科学阅读等具体材料。标题采用陈述句；说明和出处集中在“资料”面板。

直接打开 `index.html` 即可离线演示，无需安装依赖或构建。方向键或空格切换整页，F 全屏，G 目录，N 讲稿。第14页“结合建设实践研读政治经济学”保留翻页，共两个跨页。第7页改为批注图片与原文并列的固定版式，其余页面直接展示内容。史料图片可点击放大。

键盘焦点位于书页内时，左右方向键切换内部书页；整页切换使用右下角箭头。滚轮只在书页区域内生效。讲稿与独立的 `speaker-notes.txt` 已按新页序同步，主讲正文约5020个汉字。页面时长合计18分50秒，另预留约1分钟展示和换页，供20分钟汇报排练参考；实际时长以排练为准。

投影版使用统一的标题、分题、正文和引文层级。正文通常26px，附录正文24px，必要图片说明22px；删除正文区域的细小引用标签和多余序号。主标题54px，分题30px，引文34px。所有图片均在 `assets/`。

浏览器打印为白底横版19页，每个翻书组件只保留初始跨页；完整摘读请使用网页。书页是文献短摘与材料整理，并非原书扫描。原书实际版本与页码仍需按小组用书核对；公开出处和材料定位在“资料”面板中保留。

验证：

node --check course/slides.js
node --check course/app.js
node --test tests/course.test.cjs
