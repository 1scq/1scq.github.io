# 毛泽东的读书生活 · 小组展示

21页网页演示：19页正文、2页附录。沿用原有版式与翻书效果，新增古诗考据、政治经济学读书小组、两处理论讨论和自然科学阅读。原有17页的相对顺序保留。

直接打开 `index.html` 即可离线演示，无需安装依赖或构建。方向键或空格切换整页，F 全屏，G 目录，N 讲稿。第7、8、10、11、13、16、17页支持鼠标滚轮、页角和标签翻阅，共18个摘读跨页。史料图片可以点击放大，出处集中在“资料”面板。

键盘焦点位于书页内时，左右方向键切换内部书页；整页切换也可以使用右下角箭头。讲稿弹窗显示在当前页面，备讲补充默认折叠；需要独立阅读时请使用 `speaker-notes.txt`。

所有图片均在 `assets/`。浏览器打印输出21个横版页面，每个翻书组件只保留初始跨页；完整内容请使用网页演示。书页是文献短摘与材料整理，并非原书扫描。

讲稿以小组提供的原逐页讲稿为底稿修订。19页主讲正文共5764个汉字（不计翻页提示），另有808字备讲。按每分钟280—300字、另加90秒翻页停顿估算，约21—22分钟；每分钟330字时约19分钟，可选用备讲。字数估算不是真人实测，页面时长标注只作排练参考。原书实际版本与页码仍需按小组用书核对；新增材料已提供公开出处与段落定位。

从仓库根目录运行静态检查与内容关联测试：

```sh
node --check course/slides.js
node --check course/app.js
node --test tests/course.test.cjs
```

逐页修改说明见 `docs/course-expansion-review.md`。
